# Triage Labels

各 skill 用五个规范的 triage 角色来表述。本文件把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 规范角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分描述，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

当某个 skill 提到某个角色（例如「打上 AFK-ready 这个 triage 标签」），就用上表对应行的标签字符串。

若将来改用别的命名，直接改「本仓库的标签」这一列即可。
